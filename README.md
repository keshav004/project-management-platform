# project-management-platform
A full-stack enterprise-style project management platform built with ASP.NET Core, Angular, SQL Server, and Azure, demonstrating clean architecture, secure authentication, role-based authorization, and cloud-native development.

## Tech Stack

### Frontend
- Angular
- TypeScript
- Angular Material

### Backend
- ASP.NET Core
- C#
- Entity Framework Core

### Database
- SQL Server

## Features

- JWT Authentication
- Role-Based Authorization
- User Management
